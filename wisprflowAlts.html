Wispr Flow alternatives: install & setup guide

Nine dictation apps that run on both Mac and Windows. Press a shortcut, speak, and your words appear in any app. Pick one, follow the steps, and start practising your English out loud.

Which one? If you want free and unlimited, start with the local-first tools: Handy, Amical, OpenWhispr or Spokenly. They run speech recognition on your own computer, so there’s no word cap. The cloud tools (Willow, Typeless, Aqua Voice) have free tiers with limits. Accuracy hasn’t been compared here, so try two and keep the one you like.

Setup guides

Tap a tool to open its steps. Shortcuts can be changed in each app’s settings.

HandyFree · open sourceMac · Windows · Linux

Press a shortcut, speak, and the text appears in any field. Everything runs offline on your computer.

Mac

  1. Download from handy.computer or GitHub Releases, then drag it to Applications. Or run brew install --cask handy.
  2. Open Handy and allow Microphone and Accessibility.
  3. Set your shortcut in Settings: hold to record, or tap to toggle.
  4. Click in any text field, press the shortcut and speak.

Windows

  1. Download the installer from GitHub Releases, or run winget install cjpais.Handy.
  2. Open Handy and allow the microphone.
  3. Set your shortcut in Settings.
  4. Click in any text field, press the shortcut and speak.

Models: Whisper (Small to Large) or Parakeet V3 (runs on the CPU). Homebrew and winget packages are community-maintained. Official site

AmicalFree local · MITMac · Windows

Local-first dictation with a floating widget and custom hotkeys. Works offline.

Mac

  1. Run brew install --cask amical, or download from amical.ai.
  2. Open it. First-run setup downloads a local model and asks for microphone and system permissions.
  3. Set your hotkey, click in any text field and speak.

Windows

  1. Download the Windows installer from the latest release.
  2. Open it. First-run setup downloads a local model and asks for permissions.
  3. Set your hotkey, click in any text field and speak.

Local dictation is unlimited. Its billing docs describe monthly caps on cloud models and paid plans.

OpenWhisprFree local · MITMac · Windows · Linux

Dictate into any app with a global hotkey, using local or cloud models.

Mac

  1. Download the .dmg from Releases, or run brew install --cask openwhispr (community-maintained).
  2. Install and open it, then pick a local model. Its docs recommend Orukeet; Whisper and Parakeet also work offline.
  3. Allow the permissions it asks for (Microphone is required).
  4. Press your hotkey and speak.

Windows

  1. Download the .exe from Releases.
  2. Install and open it, then pick a local model.
  3. Allow microphone access.
  4. Press your hotkey and speak.

Free: unlimited local models plus 2,000 cloud words a week. Pro: $80/yr. Quickstart docs

SpokenlyFree localMac · Windows · Linux · iOS

Local Whisper and Parakeet models with no word cap, or plug in your own API key.

Mac

  1. Download from spokenly.app. No account is needed to start.
  2. Download a local model, or add your own API key for a cloud model.
  3. Set a global shortcut, click in any text field and speak.

Windows

  1. Open spokenly.app/windows and install from the Microsoft Store (a direct installer is offered if the Store is blocked).
  2. Download a local model (Parakeet V3 is its suggested start) or add your own API key.
  3. Default shortcut is Ctrl+Win. Click in any text field and speak.

Free: local models, no limit. Local+ $29 one-time. Pro $9.99/mo. Needs Windows 10 (1809+) or 11, 64-bit.

SuperwhisperFree local · Pro paidMac · Windows · iPhone · Android

Fast dictation with “modes” that shape the text into messages, emails or notes.

Mac

  1. Download from superwhisper.com, open the file and drag it to Applications.
  2. Allow Microphone and Accessibility.
  3. In the wizard choose your language, model (cloud or local) and microphone. The defaults work.
  4. Default shortcut is Option+Space: press to start, press again to stop.

Windows

  1. Download the installer from superwhisper.com/windows and run it. It starts automatically and lives in the system tray.
  2. Allow microphone access.
  3. Set your shortcut in Settings, click in any text field and speak.

Free: unlimited local dictation. Pro: $8.49/mo, $84.99/yr or $249.99 lifetime. One license covers Mac, Windows, iPhone and Android.

VoiceTyprPaid · one-timeMac · Windows

Open source (AGPL), offline-first. After a short trial you buy a lifetime license, with no subscription.

Mac (macOS 14+)

  1. Download from voicetypr.com/download or GitHub Releases.
  2. Open the app, allow Microphone and Accessibility, and download a transcription model.
  3. Set the recording shortcut in General settings, click in a text field, press it and speak.

Windows (10 build 19041+ / 11)

  1. Use the direct installer or the Microsoft Store listing.
  2. Open the app and download a transcription model.
  3. Set the shortcut in General settings, click in a text field, press it and speak.

Trial is 3 days. Prices of $39 to $99 come from third-party listings, so confirm on the site.

Willow VoiceFree tier · cloudMac · Windows · iOS

Cloud dictation that types into any app. Android is listed as coming soon.

Mac

  1. Download from willowvoice.com/download, open the file and drag Willow to Applications.
  2. Open it. Onboarding asks for Microphone and Accessibility.
  3. Hold fn and speak. You can add up to four custom hotkeys in Settings.

Windows

  1. Download from willowvoice.com/download and run the installer.
  2. Open it and allow the permissions it asks for.
  3. Check your hotkey in Settings first, because Willow’s own pages list different Windows defaults (Win+Left Shift and Alt+Space).

Free: 2,000 words a week. Individual: $15/mo or $12/mo billed yearly. Pro adds offline dictation.

TypelessFree tier · cloudMac · Windows · Linux · iOS · Android

AI voice keyboard that cleans up what you say. Its pricing page lists zero cloud data retention.

Mac

  1. Go to typeless.com and click Download for macOS.
  2. Allow Accessibility (so it can paste text) and Microphone.
  3. Click in a text field, press Fn and speak. Listen for the sound or watch the white bars move.

Windows

  1. Download the Windows app from typeless.com.
  2. Allow microphone access when asked.
  3. Default shortcut is Right Alt. Click in a text field, press it and speak.

Free: a limited number of words each week (it doesn’t publish the number). Pro: $30/mo or $12/mo billed yearly. Pricing

Aqua VoiceFree trial words · cloudMac · Windows · iOS · Android

Hold a key, talk, let go. It needs an account and an internet connection.

Mac

  1. Download from aquavoice.com/mac (one download for Apple silicon and Intel). Drag it to Applications.
  2. Allow Microphone and Accessibility, and sign in.
  3. Hold Fn (the Mac default), talk, release.

Windows

  1. Download the installer from aquavoice.com/windows and run it.
  2. Allow microphone access and sign in.
  3. Pick your hold-to-talk key in Settings, then hold it, talk and release.

Free: 1,000 words in total, no weekly refill. Pro: $12/mo or $10/mo billed yearly.

Practise speaking English (2 minutes a day)

  1. Open any app where you can type: Notes, Docs, or a chat window.
  2. Hold your shortcut and answer out loud: “Tell me about yourself,” as if you were in a real interview.
  3. Read the text on screen. Mark where you struggled or got stuck.
  4. Refine your wording and try again.
  5. Repeat with any topic or a mock interview, for a couple of minutes every day.

Good to know

  • Prices and limits change. They were taken from each tool’s own pages on 9 November 2026, except VoiceTypr’s prices (third-party listings). Check before you pay.
  • “Free and unlimited” applies to the local models of Handy, Amical, OpenWhispr, Spokenly and Superwhisper’s free tier. Cloud features have their own limits.
  • Homebrew and winget packages for Handy and OpenWhispr are maintained by the community, not the developers.
  • These apps weren’t tested for accuracy, so no accuracy claims are made.
